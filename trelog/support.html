About

アプリについて

BUFFは、日々のワークアウトを記録し、成長を可視化するアプリです。記録・統計・バックアップなどの基本機能はオフラインで使えます。希望する場合は、同じApple AccountのiPhoneとiPadでワークアウト記録のiCloud同期を有効にできます。

Features

主な機能

🏋️ トレーニング記録

重量・回数を素早く記録。器具の重量・追加重量のみ・体重＋加重・補助、有酸素運動（時間・距離・カロリー）に対応。セット種別、セットごとのメモ、前回値表示で日々の進捗を確認できます。

📊 統計とグラフ

概要・振り返り・ベスト記録・分析の4画面で記録を確認。週間目標の編集、過去の週目標の確認付き復元、週次・月間・年間レポート、CSV・共有画像の出力に対応しています。

👤 身体データ管理

体重・体脂肪率・身長・周径囲を記録し、推移グラフで変化を可視化。Appleヘルスケアアプリとの双方向同期にも対応しています。

📋 テンプレート機能

よく行うワークアウトを保存し、再利用できます。お気に入りをメニュー調整に活用でき、複数週のプログラムではルーティンの実施順と次回の目標を管理できます。

⏱️ インターバルタイマー

セット間の休憩時間を計測。Dynamic Islandにカウントダウンを表示。ワークアウト画面にフローティングミニタイマーを常時表示NEW。よく使う時間はプリセットとして登録できます。

💾 バックアップ・復元

設定画面からJSONバックアップを作成・復元できます。自動バックアップの世代管理にも対応し、機種変更時の復元にも利用できます。

❤️ ヘルスケア連携 NEW

身体データの取り込み・書き出し・競合内容を同期前にプレビューできます。ワークアウト時間はBUFFで計測して保存するか、Apple Watchなどの既存ワークアウトと対応付けます。

☁️ iCloud同期

同じApple AccountのiPhoneとiPadで記録・計画・プログラムを同期。対象への同意後は、BUFFで入力した身体データ・周径囲・進捗写真や対象の設定も同期できます。競合は内容を確認して解決します。

📸 進捗写真

プロフィールタブから写真・日付・メモを記録。写真は端末内に保存され、JSONバックアップ・復元の対象です。iCloud同期で身体データ・写真などの同期に同意すると、端末間でも同期できます。

🤖 AIトレーナー

記録に基づく質問やトレーニングの提案を端末内で処理。AIチャットはiOS／iPadOS 26以上の対応端末で、Apple Intelligenceが有効かつモデルの準備が完了している場合に利用できます。

📱 ウィジェット

ホーム画面・ロック画面に今日の実績やストリークを表示。中サイズではストリーク・今週のセット数・ボリューム・カロリーを追加表示。大サイズは今日/今週/今月/最終トレーニング日をセクション別に表示します。

🏠 場所・器具とメニュー調整

自宅・ジム・両方の環境と使える器具、重量、時間を登録。お気に入りや最近の記録も踏まえてメニューを調整でき、重量欄では登録した候補から選択できます。

Tips

使い方のヒント

  • チュートリアル表示　— プロフィールタブ → 設定 → ワークアウト設定 → チュートリアルを表示
  • 前回の値を使用　— 未編集のセット行に「前回」が表示される場合、そのボタンから前回値を入力できます
  • 前回値の確認　— 種目カードのヘッダーで前回の記録を確認できます。追加重量のみの種目は、体重を加算せず追加重量と回数を区別します
  • 前回との比較　— 種目カードに「回数アップ」「ボリューム向上」など、記録内容に応じた進捗を表示
  • セット複製　— セット行の「複製」ボタンで入力済みのセットを素早く追加
  • 種目の並び替え　— 種目カードを長押ししてドラッグで並び替え可能
  • 種目・セットの表示順　— プロフィールタブ → 設定 → ワークアウト設定で、それぞれ「新しい順」「古い順」を選択
  • フローティングタイマーNEW　— タイマー起動中はワークアウト画面下部にミニタイマーが常時表示
  • 日ごとの記録を確認　— 統計 → 概要のカレンダーで日付を選択すると、全種目・全セットの明細を閲覧できます。内容の編集はワークアウトタブで対象の日付を選んで行います
  • 週間目標やレポートを確認　— 統計 → 振り返りへ移動。「部位バランス」「累計の統計」は必要なときに開けます
  • ワークアウト画像を共有　— ワークアウトのメニュー →「今日のトレーニングを共有」で、テンプレート・サイズとプレビューを確認して共有。記録が多い場合は複数枚に分割します
  • CSVエクスポート　— 統計タブの共有ボタンからトレーニングデータをCSV出力・共有可能
  • 前回・次回ナビゲーション　— ワークアウト／統計タブで前回・次回のトレーニング日にワンタップ移動
  • お気に入り種目　— よく使う種目・テンプレートをお気に入りに追加して素早くアクセス
  • ヘルスケア連携　— プロフィールタブ → 設定 → ヘルスケア連携からAppleヘルスケアとの同期を設定。手動同期では差分と競合をプレビューできます
  • iCloud同期　— プロフィールタブ → 設定 → iCloud同期で有効化。設定画面から「今すぐ同期」や「同期データを確認」を利用できます
  • 場所・器具の登録　— プロフィール → 設定 → ワークアウト設定 →「場所・器具／いつもの条件」
  • 登録重量の候補　— 器具の重量を登録し、設定 → 一般 →「登録重量を候補から選ぶ」をON（初期状態はOFF）
  • 過去の週目標　— 統計 → 振り返り →「過去の週目標を確認」から保存内容と週の区切りを確認して復元
  • タイマープリセット　— よく使う休憩時間をプリセット登録して素早く設定
  • 入力モード切り替え　— プロフィールタブ → 設定 → 一般 →「テキスト入力モード」で、キーボード入力とダイヤル入力を切り替え
  • 種目検索　— 種目タブの検索バーで種目名・主動筋・補助筋を横断検索
  • 一括編集NEW　— 種目タブの編集モードで複数種目を選択し、一括アーカイブ・ジム/家設定が可能
  • 初期種目の復元　— 設定 → メンテナンス・データ管理 → 「初期種目を復元」で削除・アーカイブした初期種目を復元
FAQ

よくある質問

日ごとの種目・セット内容はどこで確認できますか？

統計 → 概要のカレンダーで日付を選んでください。その日の集計と各種目の全セットを、編集せずに確認できます。種目の履歴ボタンから過去の記録や推移グラフも開けます。編集するときはワークアウトタブで対象の日付を選んでください。

統計のレポートや殿堂が見つからない

週次・月間・年間レポートと週間目標は「振り返り」タブにまとまりました。「部位バランス」「累計の統計」は折りたたみ表示で、開閉状態は次回起動時も保持されます。称号を一覧にした「殿堂」の表示は廃止しました。

ワークアウトから他のタブへ移動できない・動作が重い

変更した入力は保存してからタブを移動します。保存中にタブを選び直した場合は、最後に選んだタブへ移動します。保存エラーが表示される場合は、入力を保護するためワークアウト画面に留まります。症状が続く場合は下記の窓口へお問い合わせください。原因確認のためにアプリを削除したり、記録を消去したりする必要はありません。

データはどこに保存されますか？

データは基本的にお使いのデバイス内へ保存されます。iCloud同期を有効にした場合、記録・計画・プログラムがAppleのiCloudへ送信・保存されます。同期対象への同意後は、BUFFで入力した身体データ・周径囲・進捗写真や対象の設定も同期されます。HealthKit由来のデータと端末ごとの権限設定は含みません。

別の端末でiCloudの記録を使うには？

同じApple Accountでサインインし、プロフィールタブ → 設定 → iCloud同期を有効にします。初回の選択画面で「iCloudの内容」を選びます。既に記録がある端末でも、端末とiCloudの記録を残して同期します。同じ記録の内容が異なる場合は確認してから反映します。参加できない案内が出た場合は、記録を削除せずバックアップを作成してください。詳しくはマニュアルのiCloud同期をご覧ください。

追加重量0kgなのにボリュームが0になるのは？

「追加重量のみ」は体重を含めず、追加した重量×回数で集計します。0kgでも回数の実績は保存され、種目の履歴で総回数・1セット最多などの推移を確認できます。3kg×30回なら追加重量ボリュームは90kgです。記録方式と過去の記録への適用もご確認ください。

以前の週目標を復元するには？

対象の保存内容がある場合、統計 → 振り返りに「過去の週目標を確認」が表示されます。「保存内容を表示」で日付・目標・タイムゾーン・週の開始曜日を確認し、復元できる場合は「この週の区切りで復元」を選びます。元の内容と既存の週目標は保持されます。詳しい手順をご覧ください。

「週目標の共有を保留中」と表示される場合は？

同期に使うすべての端末のBUFFを更新し、更新確認の案内に従ってください。保留中も元の週目標は保持されます。

データのバックアップは？

設定画面からJSONバックアップを作成・復元できます。自動バックアップの保持世代数も選択できます。iOSのiCloudバックアップを使用している場合は、iOS側のバックアップ対象にもなります。

トレーニングデータをエクスポートできますか？

統計画面右上の共有ボタン →「CSVで共有」から出力できます。概要・振り返り・ベスト記録・分析のどのサブタブからも利用できます。Excel互換のBOM付きUTF-8形式で出力され、共有シートから他のアプリに送れます。

ヘルスケアアプリのデータを変更したい場合は？

ヘルスケア側のデータを直接変更したい場合は、Appleのヘルスケアアプリ内で編集してください。次回同期時に差分が表示され、BUFFへ取り込む内容を確認できます。

データを削除するには？

各データの左スワイプで削除できます。削除したセッションはゴミ箱から30日以内に復元可能です（30日を超えると自動クリーンアップされます）。ヘルスケア側のデータはAppleのヘルスケアアプリで管理してください。

Dynamic Islandにタイマーが表示されない

プロフィールタブ → 設定 → 一般で「ダイナミックアイランド」を有効にし、iOSの設定アプリでBUFFのライブアクティビティが許可されているか確認してください。Dynamic Islandに対応していない機種では、ロック画面に表示されます。

オフラインでも使えますか？

ワークアウトの記録・統計・バックアップなどの基本機能はオフラインで使えます。iCloud同期にはインターネット接続が必要です。AIトレーナーは対応する端末内で処理します。

AIトレーナーに記録や会話が送信されますか？

送信されません。AIトレーナーはApple Intelligenceのオンデバイスモデルを使用し、選択した記録と会話内容を端末内で処理します。AIチャットはiOS／iPadOS 26以上の対応端末で、Apple Intelligenceが有効かつモデルの準備が完了している場合に利用できます。

削除・アーカイブした初期種目を復元したい

プロフィールタブ → 設定 → メンテナンス・データ管理 →「初期種目を復元」から、個別に選択して復元できます。
