# Fotrail 2.1 公開サイト最新化 設計

## 目的

公開中のFotrailサポートサイトを、App Storeで公開中のFotrail 2.1.0と一致させる。現在のダークテーマ、ルートを主題にしたビジュアル、静的HTML構成は維持し、古い機能説明とプライバシー上の矛盾を解消する。

## 対象

- `Fotrail/index.html`
- `Fotrail/support.html`
- `Fotrail/privacy-policy.html`
- `Fotrail/styles.css`は、App Storeボタンの追加に既存スタイルで対応できない場合だけ最小限変更する。

## 情報源

- 2026年8月3日時点のApp Store公開版2.1.0
- Fotrail 2.1.0 (57)の更新履歴と実装済み機能
- 現在公開中の3ページと共通スタイル

サイトの説明は公開版の機能だけを対象とし、未公開機能や将来予定を掲載しない。

## 更新方針

既存ページへ説明を継ぎ足すのではなく、現在のカード、セクション、FAQという構造の中で情報を再編する。App Storeの商品説明をそのまま転載せず、トップページは概要、サポートページは操作と問題解決、プライバシーポリシーは情報の取得・処理・保存・共有・削除へ役割を分ける。

新しいJavaScript、外部フォント、分析ツール、Cookie、開発者サーバーへの通信は追加しない。

## トップページ

### ヒーロー

- 主メッセージを、GPSログの作成だけでなく「写真の撮影場所をあとから確認・追加できる」価値へ更新する。
- GPS記録、写真のExif撮影時刻との照合、確認後の位置情報追加が端末内で完結することを短く説明する。
- 最優先のボタンとして、公開中のApp Store商品ページへのリンクを追加する。
- 「使い方を見る」と「データの扱いを確認」は副導線として残す。
- 外部リンクであることが支援技術でも理解できるラベルにする。

### 主な機能

既存の6枚カードを次の内容へ再編する。

1. バックグラウンドGPS記録
2. Exif撮影時刻とGPS地点の照合
3. 写真への位置情報追加
4. 原画質を保持した写真付きルート共有
5. Live Activity、Widget、ショートカットからの記録操作
6. ローカルファーストと任意のiCloud Drive保存

説明には、次の境界を含める。

- 写真アプリでは、ユーザーが確認した写真の位置情報を更新し、処理記録が残っている間は直前の位置へ戻せる。
- JPEG・HEIC等のファイルは上書きせず、位置情報付きの新規コピーを作る。
- RAWは元ファイルを変更せず、XMPサイドカーを作る。
- 撮影ルート共有は、JPEG・HEIC・PNG・Live Photosに対応し、RAW添付は対象外とする。
- 位置は撮影時刻とGPSログから求める目安であり、厳密な撮影地点を保証しない。

### ローカルファースト

現在のセクションを維持し、位置情報、写真、Exif、照合結果、共有用データを開発者の独自サーバーへ送信しないことを明記する。写真ライブラリ全体を自動走査せず、ユーザーが選んだ項目だけを処理することも記載する。

## サポートページ

### 基本の使い方

単一の長い手順にせず、次の3つの利用目的を短い手順へ分ける。

1. 撮影中のGPSを記録する
2. 撮影後に写真へ位置情報を追加する
3. 写真付きの撮影ルートを共有する

GPS記録の手順には、開始、一時停止・再開、安全な場所での終了、履歴確認、GPX共有を含める。

位置情報追加の手順には、記録または外部GPXの選択、写真選択、時刻・タイムゾーン・カメラ時計差の確認、信頼度確認、出力方法確認、実行を含める。

撮影ルート共有には、記録への写真添付と次の4形式を掲載する。

- ルートカード
- GPXと原本を含むZIP
- 個別項目
- オフラインHTMLアルバム

### FAQ

既存の位置情報、バックグラウンド記録、精度、保存間隔、iCloud Drive、削除、安全上の説明は、2.1.0の挙動に合わせて維持・修正する。

古い「写真ライブラリやカメラを使用せず、写真へ直接変更しない」という回答は削除し、次のFAQへ置き換える。

- どの写真へアクセスするか
- 写真アプリの写真はどのように変更されるか
- 位置情報の変更を取り消せるか
- JPEG・HEIC・RAWの出力方法の違い
- 外部GPXを使えるか
- 撮影時刻と位置が一致しない場合
- Live Photosを共有した場合
- 4つの共有形式の違い
- 添付した写真と完全バックアップの削除・復元

FAQでは保証できない動作を断定しない。iCloud上だけにある写真、カメラ固有RAW、限定写真アクセス、バックグラウンド記録は、端末状態やiOSの制約を受けることを必要な箇所で明示する。

## プライバシーポリシー

最終更新日は実際に公開する日付とする。構成は次の責務が区別できるように整理する。

### 取得・処理する情報

- GPS記録と一時的な地名候補取得に使う位置情報
- 記録名、メモ、撮影メモ、カメラ設定、GPX等の端末内データ
- 参考写真と任意の写真アプリへの追加
- ユーザーが位置情報追加のために選んだ写真、Exif撮影日時、タイムゾーン、既存GPS、画像形式・寸法・向き
- ユーザーが撮影ルート共有のために選んだJPEG・HEIC・PNG・Live Photos

写真ライブラリ全体の自動走査、未選択写真の収集、待機中の継続測位を行わないことを明記する。

### 写真への位置情報追加

- 実行前に候補地点、信頼度、既存GPS、時刻補正、出力方法を確認する。
- 写真アプリでは選択写真の位置情報を更新し、取り消し用情報を端末内に保持する。
- ファイルでは元画像を上書きせず新規コピーを作る。
- RAWでは元ファイルを変更せず新しいXMPを作る。
- 中断後に自動で写真変更を再開しない。

### 写真付きルート共有

- 添付写真はユーザーが明示的に選び、対応する記録へ端末内保存する。
- 写真位置は撮影時刻とGPSログに基づく目安である。
- ルートカードとHTMLアルバムには、写真メタデータを除いた派生画像を使う。
- 原本ZIPと個別共有では、原本の解像度とメタデータを保持する。
- Live Photosは静止画とペア動画を扱う。不完全なLive Photoを黙って別形式へ変換しない。
- RAWは撮影ルートへの添付対象外である。

### 保存、共有、バックアップ、削除

- iCloud Driveへの自動保存はユーザーが有効にしたGPXを対象とし、開発者サーバーではない。
- 共有はユーザーが共有操作を選んだ場合だけiOS共有画面へ渡す。
- 完全バックアップには、GPSログ、GPX、各種メモ、参考写真に加え、撮影ルート共有用の原本、Live Photosのペア動画、サムネイルが含まれる場合がある。
- 記録削除、写真照合ジョブ、写真アプリの変更、Filesへ作成したコピー・XMP、共有先に渡した項目を区別して削除方法を説明する。
- アプリ削除後もiCloud Drive、写真アプリ、Files、共有先に作成済みの項目が残る場合があることを明記する。

### 第三者サービスと問い合わせ

AppleのCore Location、MapKit、写真ライブラリ、iCloud Drive、iOS共有機能を、ユーザーが選んだ機能に応じて利用することを記載する。広告、第三者追跡、行動分析、独自アカウントは使用しない。問い合わせメールで受け取る情報と利用目的も現在の方針を維持する。

## アクセシビリティとレスポンシブ表示

- 現在の見出し階層、ランドマーク、ナビゲーションラベルを維持する。
- リンク文言だけで移動先が分かるようにする。
- 色だけで機能や注意を区別しない。
- スマートフォン幅では既存どおりカードを1列にする。
- 3つのヒーローボタンは折り返しても重ならず、44pt相当以上の操作領域を保つ。
- `prefers-reduced-motion`への既存対応を維持する。

## 検証

1. 3つのHTMLを標準HTMLパーサーで読み込み、構文上の破綻がないことを確認する。
2. ホーム、サポート、プライバシー間の相対リンク、App Storeリンク、メールリンクを確認する。
3. 「写真ライブラリを使用しない」「写真へ変更しない」等の2.1.0と矛盾する旧表現が残っていないことを検索する。
4. 2.1.0の主要機能とプライバシー項目が各ページの役割に応じて掲載されていることをチェックリストで照合する。
5. デスクトップ幅とスマートフォン幅で3ページを表示し、ナビゲーション、ボタン、カード、FAQ、長文の折り返しを確認する。
6. JavaScript、外部分析、意図しないフォーム送信、危険なイベント属性を追加していないことを確認する。
7. 変更差分とGit状態を確認し、対象4ファイルとこの設計・実装計画以外を含めない。

## 対象外

- 全面デザイン変更
- 新しい画像、スクリーンショット、動画の追加
- 英語版ページの追加
- App Storeの商品説明やスクリーンショットの変更
- アプリ本体の変更
- アカウント、公開URL、SNS、バックエンド、分析基盤の追加
- GitHub Pagesのドメイン、公開方式、リポジトリ設定の変更

## 完了条件

- 公開サイトの説明がFotrail 2.1.0と矛盾しない。
- App Storeへの明確な導線がトップページにある。
- 写真アクセス、位置情報変更、原本共有、Live Photos、バックアップ、削除がプライバシーポリシーに明記されている。
- 現在の外観と静的サイト構成が維持される。
- 構文、リンク、レスポンシブ表示、旧表現検索の検証が完了する。
